API Reference

Inputs

Input Type Default Description
variant 'primary' | 'primary-light' | 'secondary' | 'danger' | 'ghost' 'primary' Button style variant
size 'sm' | 'md' | 'lg' 'md' Button size
shape 'default' | 'full' | 'circle' 'default' Button shape (rounded, pill, full-width)
disabled boolean false Disable button interaction
loading boolean false Show loading spinner, disable interaction
type 'button' | 'submit' | 'reset' 'button' HTML button type attribute

Outputs

Output Type Description
clicked void Emits when button is clicked (not emitted when disabled/loading)

Content Projection

Slot Description
default Button text content
iconLeft Icon element before text (add iconLeft attribute)
iconRight Icon element after text (add iconRight attribute)
