Pagination

A self-managed page navigator with adaptive page ranges.

Basic Usage

The component manages its selected page internally; initialPage only chooses its starting page.

<app-pagination [totalPages]="12" [initialPage]="6" />

Adaptive Page Range

The first and last pages remain visible. The selected page and one adjacent page on each side appear when available; ellipses mark hidden ranges.

Reacting to Page Changes

Use pageChanged to load data. It does not need to be used to control the pagination UI.

<app-pagination
  [totalPages]="totalPages"
  (pageChanged)="loadPage($event)"
/>
