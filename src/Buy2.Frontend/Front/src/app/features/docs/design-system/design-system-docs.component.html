Design System

Visual language and design tokens for the HR Management System.

Overview

System Name

HRMS Design System

Version

1.0.0

Brand Color

#234199

Framework

Angular 21 + Tailwind CSS

A centralized design token system for consistent UI across the HR Management System. All colors, spacing, and typography are defined as CSS custom properties and exposed through Tailwind CSS for rapid development.

How to Use Tokens

In Tailwind CSS (Recommended)

<!-- Background colors -->
<div class="bg-primary-600">Primary background</div>
<div class="bg-error-50">Error background</div>

<!-- Text colors -->
<p class="text-neutral-800">Dark text</p>
<p class="text-primary-600">Brand text</p>

<!-- Border colors -->
<input class="border border-error-500" />  <!-- Error state -->
<div class="border border-neutral-200"></div>

<!-- Hover states -->
<button class="bg-primary-600 hover:bg-primary-700">Hover me</button>

In Normal CSS

.my-component {
  /* Use CSS custom properties directly */
  color: var(--color-neutral-800);
  background: var(--color-primary-600);
  border: 1px solid var(--color-neutral-200);
}

.my-component:hover {
  background: var(--color-primary-700);
}

.my-component--error {
  border-color: var(--color-error-500);
  color: var(--color-error-600);
}

In SCSS (if needed)

$primary-600: var(--color-primary-600);
$neutral-800: var(--color-neutral-800);

.my-component {
  color: $neutral-800;
  background: $primary-600;
}

Color System

Colors follow a 10-shade scale (50-900) where 50 is lightest and 900 is darkest. Use 600 for primary actions, 700 for hover states.

Token Naming Convention

Pattern Example Usage
--color-{palette}-{shade} --color-primary-600 Color tokens
--spacing-{element}-{axis} --spacing-table-x Component spacing
--radius-{element} --radius-table Component border radius
--color-{palette}-overlay --color-primary-overlay Transparent version for backgrounds

Shade Scale: 50 (lightest bg) → 100-200 (light borders) → 300-400 (disabled) → 500 (medium) → 600 (primary) → 700 (hover) → 800-900 (darkest)
