Modal Component

Dialog overlay with header, body, and actions. Supports sizes, backdrop close, and escape key.

Selector

<app-modal>...</app-modal>

Basic Usage

@if (basicModal()) {

  </app-modal-body>

Close Behavior

No Backdrop Close
@if (noBackdropModal()) {

Backdrop Disabled

Clicking outside does nothing. Press Escape or click the button to close.

Close } 
<!-- Disable backdrop click -->
<app-modal [closeOnBackdrop]="false" ...>

<!-- Disable escape key -->
<app-modal [closeOnEscape]="false" ...>

<!-- Disable both -->
<app-modal [closeOnBackdrop]="false" [closeOnEscape]="false" ...>

API Reference

app-modal Inputs

Input Type Default Description
size 'small' | 'medium' | 'large' 'medium' Modal width (360px / 500px / 900px)
showCloseButton boolean true Show/hide close button (top-right)
closeOnBackdrop boolean true Close when clicking outside modal
closeOnEscape boolean true Close when pressing Escape key

app-modal Outputs

Output Type Description
closed void Emits when modal is closed (backdrop, escape, or programmatic)

Sub-components

Component Selector Description
ModalHeaderComponent app-modal-header Top section with title
ModalBodyComponent app-modal-body Main content area (scrollable)
ModalFooterComponent app-modal-footer Bottom section with buttons (flex, gap 16px)
